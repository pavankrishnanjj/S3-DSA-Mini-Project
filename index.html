Where each DSA concept is used

  • Hash table (chaining): PNR lookup, O(1) average
  • Linked-list queue: waiting list per train (FIFO promotion)
  • Stack: cancelled bookings, restore the latest first
  • Array: seat map per train, linear scan for a free seat
  • Merge sort: sorted bookings table, O(n log n)
